VISHAL JADON — STATIC PORTFOLIO

Open index.html in a modern browser. No installation, build process, server,
environment variables, API keys, accounts, or database are required.

Project entry points:
  index.html
  style.css
  script.js
  assets/

The complete 3D experience requires a WebGL-capable browser. A fallback
presentation is provided when WebGL is unavailable. The motion control in the
footer and the operating system's reduced-motion setting reduce animation.

Photography and the extracted credential are authentic supplied assets. The
portrait is a background-isolated source photograph: no replacement person,
fabricated legs, facial alterations, or invented credentials/statistics.
Embedded image data in assets/textures.js allows WebGL textures to load when
index.html is opened as a local file. Relative image files serve the full-size
viewers and fallback presentation.

Locally included browser libraries:
  Three.js r158 — https://threejs.org/ (MIT; classic browser build)
  GSAP 3.14.2 / ScrollTrigger — https://gsap.com/standard-license/
  Lenis 1.3.19 — https://github.com/darkroomengineering/lenis (MIT)
  Motion 12.23.26 — https://motion.dev/ (MIT, vanilla browser engine)
  Manrope / Syne fonts — Google Fonts, SIL Open Font License

The classic Three.js build emits an upstream deprecation notice in developer
tools. This is not an application error; it is pinned for straightforward
local-file compatibility without a module build or development server.
